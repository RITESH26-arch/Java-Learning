# Java-Learning

My Java learning journey: from core basics to OOP, with hands-on practice in every topic. Goal: Core Java → Spring Boot → AWS.

## Topics Covered

| Folder | What I learned |
|--------|----------------|
| Basic | Java basics, syntax, small logic programs |
| OperatorsInJava | Arithmetic, relational, logical operators |
| Conditional | if, else, switch |
| Loops | for, while, do-while |
| NestedLoops | Pattern programs using nested loops |
| Arrays | 1D and 2D arrays |
| Methods | Method types, parameters, return values |
| String | String class and string operations |
| OOPS | Classes, objects, inheritance, polymorphism, abstraction, encapsulation |
| ExceptionHandling | try-catch, throw, custom exceptions |
| MiniProject | Member / Student / Faculty based mini project |

    java FileName
